## Contenido

### Qué es
Un **idiom** es una expresión cuyo significado no se deduce de sus palabras: *break the ice* no es romper hielo, es "romper el hielo" en una conversación (este coincide con el español; muchos no). En C1 se espera que **entiendas** los comunes y **uses** algunos con naturalidad.

### Expresiones útiles en el trabajo
| Idiom | Significado | Ejemplo |
|---|---|---|
| on the same page | estar de acuerdo / alineados | Let's make sure we're **on the same page**. |
| touch base | ponerse en contacto brevemente | Let's **touch base** on Monday. |
| a ballpark figure | un estimado aproximado | Can you give me **a ballpark figure**? |
| back to square one | volver a empezar | The test failed; we're **back to square one**. |
| cut corners | hacer algo mal para ahorrar tiempo o dinero | We can't **cut corners** on security. |
| the elephant in the room | el problema obvio que nadie menciona | The deadline is **the elephant in the room**. |
| low-hanging fruit | lo fácil de lograr primero | Let's start with **the low-hanging fruit**. |
| hit the ground running | empezar con todo desde el inicio | She **hit the ground running** in her new role. |
| up in the air | indefinido | The budget is still **up in the air**. |
| a steep learning curve | difícil de aprender al inicio | Kubernetes has **a steep learning curve**. |
| bite off more than you can chew | abarcar demasiado | Don't **bite off more than you can chew** this sprint. |
| get the ball rolling | arrancar algo | Let's **get the ball rolling** with a quick demo. |
| think outside the box | pensar diferente | We need to **think outside the box**. |
| call it a day | terminar por hoy | Let's **call it a day**. |
| in a nutshell | en resumen | **In a nutshell**, the API is too slow. |
| a no-brainer | decisión obvia | Using HTTPS is **a no-brainer**. |
| by the book | según las reglas | We did it **by the book**. |
| learn the ropes | aprender cómo funciona algo | It took me a month to **learn the ropes**. |

### Vida diaria
- **It's a piece of cake** (es pan comido) · **break a leg** (mucha suerte, antes de presentar) · **under the weather** (enfermo, sin ganas) · **once in a blue moon** (muy rara vez) · **cost an arm and a leg** (costar un ojo de la cara) · **hit the sack** (irse a dormir).

### Cómo aprenderlos
- Apréndelos **en contexto** (series, podcasts), no de listas sueltas.
- Usa primero los de trabajo; los muy coloquiales pueden sonar forzados en tu boca.
- Cuidado con variantes regionales (EE. UU., Reino Unido, Australia).

### Errores comunes de hispanohablantes
- Traducir refranes del español literalmente ("no hay mal que por bien no venga" → *every cloud has a silver lining*).
- Meter idioms en cada frase: con 1 o 2 por conversación basta.
