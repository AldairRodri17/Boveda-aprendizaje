# Inglés C1 - inversión y énfasis

Parte de: [[49-Idiomas/06 Inglés C1/_Índice Inglés C1|Inglés C1]]

> [!info] Cómo avanzar
> `progreso`: **pendiente** → **viendo** → **visto** → **dominado**.

## Contenido

### Qué es
Recursos gramaticales para **destacar** una idea. Se usan en presentaciones, escritura formal y para sonar persuasivo. Los dos principales: **inversión** (alterar el orden sujeto-verbo) y **oraciones hendidas** (*cleft sentences*).

### Cómo funciona

**1. Inversión negativa.** Cuando una frase empieza con una expresión negativa o restrictiva, el auxiliar va **antes** del sujeto (como en una pregunta):
| Normal | Con inversión |
|---|---|
| I have **never** seen such a fast API. | **Never have I seen** such a fast API. |
| We **rarely** get this kind of feedback. | **Rarely do we get** this kind of feedback. |
| He **not only** fixed the bug **but also** wrote tests. | **Not only did he fix** the bug, **but** he **also** wrote tests. |
| We realized the problem **only** after the release. | **Only after the release did we realize** the problem. |
| As soon as I arrived, the alarm went off. | **No sooner had I arrived than** the alarm went off. |
| You **shouldn't** share this **under any circumstances**. | **Under no circumstances should you** share this. |

**2. Inversión condicional (formal, sin *if*):**
- If I had known → **Had I known**, I would have called.
- If you should need help → **Should you need** help, contact me.
- If I were in your position → **Were I** in your position, …

**3. Oraciones hendidas (cleft):** reorganizan la frase para enfatizar una parte.
- *It*-cleft: **It was** the cache **that** caused the issue (no la base de datos).
- *What*-cleft: **What we need is** better monitoring.
- **All** I want is a stable build. / **The thing is**, we don't have time.

**4. Do enfático:** *I **do** understand your concern.* / *We **did** test it!*

### Cuándo usarlo
En presentaciones, documentos formales y argumentos. **Con moderación**: en una conversación casual, varias inversiones seguidas suenan teatrales.

### Errores comunes de hispanohablantes
- Olvidar el auxiliar: ~~Never I have seen~~ → **Never have I** seen.
- ~~Not only he fixed~~ → **Not only did he fix**.
- Abusar del recurso en Slack o correos simples.

## Autoevaluación

> [!question]- Reescribe con inversión: "We have rarely had such a smooth migration."
> **Rarely have we had** such a smooth migration.

> [!question]- Reescribe sin "if": "If you need anything, let me know."
> **Should you need** anything, let me know.

> [!question]- Enfatiza "la configuración" con un it-cleft: "The configuration broke the deploy."
> **It was the configuration that** broke the deploy.
