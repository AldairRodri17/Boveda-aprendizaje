## Contenido

### Qué es
El inglés profesional (sobre todo el estadounidense y el británico) tiende a **suavizar** los mensajes: críticas, desacuerdos, peticiones y malas noticias. Un mensaje gramaticalmente correcto puede sonar **grosero** si es demasiado directo. El lenguaje diplomático usa técnicas para decir lo mismo con tacto.

### Cómo funciona: técnicas
| Técnica | Directo | Diplomático |
|---|---|---|
| **Modales de duda** | This is wrong. | This **might not be** quite right. |
| **Suavizadores** (*a bit, slightly, quite*) | It's late. | It's **a bit** late. |
| **Negativo + adjetivo positivo** | It's bad. | It's **not ideal** / **not great**. |
| **Preguntas en vez de órdenes** | Change it. | **Could we** change it? / **Would it make sense to**…? |
| **Pasado / continuo** (más distancia) | I want to ask… | I **was wondering** if… |
| **Pasiva** (sin culpar) | You broke the build. | The build **was broken** by the last merge. |
| **"We" en vez de "you"** | You need to fix this. | **We** need to look at this. |
| **Reconocer antes de objetar** | No. | I **see your point**; **however**… |
| **Hedging** (no comprometerse del todo) | It will take a week. | It **should** take **around** a week. |

### Frases útiles
- **Dar malas noticias:** *I'm afraid that… · Unfortunately, … · I have some bad news regarding…*
- **Criticar con tacto:** *I wonder if we could… · One thing that might help is… · Have you considered…?*
- **Decir que no:** *I'd love to, but… · I'm not sure I'll be able to… · That might be difficult, because…*
- **Mostrar desacuerdo:** *I'm not sure I agree. · I see it slightly differently. · I take your point, but…*

### Cuidado: lo que **realmente** significan (estilo británico)
- *"With all due respect…"* → creo que estás equivocado.
- *"That's an interesting idea"* → puede significar "no me convence".
- *"I'll bear it in mind"* → probablemente no lo haré.
- *"Not bad"* → bastante bien.

### Ejemplo
**Directo:** *Your code is messy and slow. Rewrite it.*
**Diplomático:** *Thanks for the PR! I think the logic is solid. I was wondering if we could split the main method into smaller functions — it might make it easier to test. Also, the query inside the loop could be a bit slow; would it make sense to load everything at once?*

### Errores comunes de hispanohablantes
- Traducir el tono directo del español de México en contextos multiculturales.
- Exagerar la diplomacia hasta que nadie entiende el mensaje: el punto debe quedar **claro**.
