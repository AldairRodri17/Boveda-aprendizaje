# Inglés B1 - condicionales cero, primero y segundo

Parte de: [[49-Idiomas/04 Inglés B1/_Índice Inglés B1|Inglés B1]]

> [!info] Cómo avanzar
> `progreso`: **pendiente** → **viendo** → **visto** → **dominado**.

## Contenido

### Qué es
Las oraciones condicionales tienen dos partes: la **condición** (*if…*) y el **resultado**. En inglés hay varios tipos según qué tan real o probable es la situación.

### Cómo se forma
| Tipo | Uso | If + … | Resultado | Ejemplo |
|---|---|---|---|---|
| **Cero** | Verdades generales, reglas | presente simple | presente simple | If you **heat** water to 100 °C, it **boils**. |
| **Primero** | Situación real o probable en el futuro | presente simple | **will** + verbo | If the tests **pass**, we'**ll deploy** today. |
| **Segundo** | Situación hipotética o poco probable (presente/futuro) | pasado simple | **would** + verbo | If I **had** more time, I **would learn** Rust. |

**Puntos clave:**
- En la parte del *if* **nunca** va *will* (tipo 1): ~~If it will rain~~ → If it **rains**.
- En el segundo condicional, con *to be* se usa **were** para todas las personas en registro formal: If I **were** you, I'd accept the offer. (*If I was* es común en el habla informal.)
- El orden se puede invertir; si el *if* va primero, lleva coma: If it rains, … / … if it rains.
- **Unless** = if not: **Unless** you fix it, the build will fail.

### Ejemplos
- **Cero:** If the cache **expires**, the app **queries** the database.
- **Primero:** If you **send** me the specs, I'**ll** **start** tomorrow.
- **Segundo:** If I **were** a millionaire, I **would** **build** a homelab in every room.
- **Consejo:** If I were you, I **would** ask for a raise.

### Errores comunes de hispanohablantes
- ~~If I will have time, I will call you.~~ → If I **have** time, I'll call you.
- ~~If I would have money…~~ → If I **had** money…
- Confundir 1 y 2: si es realmente posible, usa el primero.

## Autoevaluación

> [!question]- ¿Qué tipo es y completa: "If you (press) ___ this button, the machine (stop) ___."
> Cero: If you **press** this button, the machine **stops**.

> [!question]- Completa: "If the client (approve) ___ the budget, we (start) ___ next week."
> If the client **approves**, we **will start** next week.

> [!question]- Corrige: "If I would be you, I will take the job."
> If I **were** you, I **would** take the job.
