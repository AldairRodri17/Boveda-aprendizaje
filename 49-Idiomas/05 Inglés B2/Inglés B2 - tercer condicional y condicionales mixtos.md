# Inglés B2 - tercer condicional y condicionales mixtos

Parte de: [[49-Idiomas/05 Inglés B2/_Índice Inglés B2|Inglés B2]]

> [!info] Cómo avanzar
> `progreso`: **pendiente** → **viendo** → **visto** → **dominado**.

## Contenido

### Qué es
- **Tercer condicional:** hipótesis sobre el **pasado** que ya no se puede cambiar. Expresa arrepentimiento o análisis de "qué habría pasado". Ideal para post-mortems.
- **Condicionales mixtos:** combinan tiempos: una condición pasada con resultado presente, o al revés.

### Cómo se forma
| Tipo | If + … | Resultado | Ejemplo |
|---|---|---|---|
| **Tercero** | **had** + participio | **would have** + participio | If we **had tested** it, we **would have found** the bug. |
| **Mixto (pasado → presente)** | had + participio | would + verbo | If I **had studied** English as a kid, I **would be** fluent now. |
| **Mixto (presente → pasado)** | pasado simple | would have + participio | If I **were** more organized, I **wouldn't have missed** the deadline. |

**Otros modales en el resultado:** could have (habría podido), might have (quizá habría).
- *If we had monitored the disk, we **could have prevented** the outage.*

**Wish / If only (arrepentimiento):**
- Presente: I **wish** I **had** more time. (ojalá tuviera)
- Pasado: I **wish** I **had taken** that job. (ojalá hubiera tomado)

**Pronunciación natural:** *would have* suena "would've" /ˈwʊdəv/. **Nunca** se escribe ~~would of~~.

### Ejemplos (post-mortem)
- If the alert **had fired** earlier, we **would have reacted** in minutes.
- If we **hadn't skipped** the code review, the token **wouldn't have leaked**.
- If we **had migrated** last year, we **wouldn't be** dealing with this now. (mixto)

### Errores comunes de hispanohablantes
- ~~If I would have known…~~ → If I **had known**…
- ~~would of~~ → would **have**.
- Usar tercero para algo que aún es posible (eso es el primero o segundo).

## Autoevaluación

> [!question]- Completa: "If I ___ (know) about the meeting, I ___ (attend)."
> If I **had known**, I **would have attended**.

> [!question]- Haz un mixto: "No aprendí a programar joven → hoy no soy senior."
> If I **had learned** to code earlier, I **would be** a senior now.

> [!question]- Corrige: "If you would have asked me, I would of helped."
> If you **had asked** me, I **would have** helped.
