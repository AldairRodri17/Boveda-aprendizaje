# Inglés B2 - cláusulas relativas

Parte de: [[49-Idiomas/05 Inglés B2/_Índice Inglés B2|Inglés B2]]

> [!info] Cómo avanzar
> `progreso`: **pendiente** → **viendo** → **visto** → **dominado**.

## Contenido

### Qué es
Las **cláusulas relativas** dan información sobre un sustantivo, como "que", "quien" o "donde" en español: "El desarrollador **que** escribió esto ya no está". Permiten unir frases cortas en una más fluida.

### Cómo funciona

**Pronombres relativos**
| Pronombre | Para | Ejemplo |
|---|---|---|
| **who** | personas | The engineer **who** designed it left. |
| **which** | cosas | The service **which** handles payments is down. |
| **that** | personas o cosas (solo en cláusulas definitorias) | The bug **that** you reported is fixed. |
| **whose** | posesión (cuyo) | The client **whose** server crashed called. |
| **where** | lugares | The office **where** I work is downtown. |
| **when** | momentos | 2020 was the year **when** we went remote. |

**Dos tipos (¡la coma importa!)**
| Definitoria (sin comas) | Explicativa (con comas) |
|---|---|
| Identifica cuál: *The laptop **that I bought** is fast.* (de varias, esa) | Agrega información extra: *My laptop, **which I bought last year**, is fast.* (solo tengo una) |
| Se puede usar *that* | **No** se puede usar *that* |
| Se puede omitir el pronombre si es objeto | No se omite |

**Omitir el pronombre:** si el relativo es **objeto** (le sigue otro sujeto), se puede quitar:
- *The book (**that**) I'm reading is great.* ✓
- *The person **who** called you* → no se puede quitar (*who* es sujeto).

### Ejemplos
- This is the function **that** causes the memory leak.
- Ana, **who** joined last month, is already leading the project.
- The cloud provider **we chose** has a free tier. (pronombre omitido)
- That's the dashboard **where** you can see all the metrics.

### Errores comunes de hispanohablantes
- Usar *what* como relativo: ~~The thing what I need~~ → The thing **that** I need (o **What** I need is…).
- Repetir el objeto: ~~The car that I bought it~~ → The car that I bought.
- Usar *which* para personas.
- Poner *that* en explicativas: ~~My boss, that is great, …~~ → My boss, **who** is great, …

## Autoevaluación

> [!question]- Une: "I met a developer. She works at Google."
> I met a developer **who** works at Google.

> [!question]- ¿Se puede omitir el pronombre?: "The tool that we use is free."
> Sí: The tool we use is free.

> [!question]- Corrige: "My manager, that lives in Spain, is very helpful."
> My manager, **who** lives in Spain, is very helpful.
