# Inglés A2 - vocabulario de trabajo, viajes y compras

Parte de: [[49-Idiomas/03 Inglés A2/_Índice Inglés A2|Inglés A2]]

> [!info] Cómo avanzar
> `progreso`: **pendiente** → **viendo** → **visto** → **dominado**. Pasa las frases (no solo palabras) a Anki.

## Contenido

### Trabajo
| Inglés | Español |
|---|---|
| job / position / role | empleo / puesto / rol |
| boss / manager / team lead | jefe / gerente / líder de equipo |
| coworker / colleague | compañero de trabajo |
| salary / raise / bonus | sueldo / aumento / bono |
| deadline | fecha límite |
| meeting / call / stand-up | junta / llamada / reunión diaria |
| to hire / to fire / to quit | contratar / despedir / renunciar |
| full-time / part-time / remote | tiempo completo / medio tiempo / remoto |
| day off / sick leave / vacation | día libre / incapacidad / vacaciones |

**Frases:** I'm in charge of… · I report to… · I'm working on… · Let's schedule a meeting. · I'll be out of office tomorrow.

### Viajes
| Inglés | Español |
|---|---|
| flight / boarding pass / gate | vuelo / pase de abordar / sala |
| check in / check out | registrarse / salir del hotel |
| carry-on / checked bag | equipaje de mano / documentado |
| delay / canceled / layover | retraso / cancelado / escala |
| round trip / one way | viaje redondo / sencillo |
| booking / reservation | reservación |

**Frases:** I have a reservation under the name… · Is breakfast included? · Where is the nearest metro station? · How do I get to…? · My flight was canceled; what are my options?

### Compras
| Inglés | Español |
|---|---|
| price / discount / sale | precio / descuento / ofertas |
| receipt / refund / exchange | ticket / reembolso / cambio |
| cash / card / change | efectivo / tarjeta / cambio (dinero) |
| size / fitting room | talla / probador |
| cheap / expensive / affordable | barato / caro / accesible |

**Frases:** How much is this? · Do you have it in a smaller size? · Can I pay by card? · I'd like to return this, please. · I'm just looking, thanks.

### Falsos amigos frecuentes
- **actually** = en realidad (no "actualmente" → *currently*).
- **carpet** = alfombra (no "carpeta" → *folder*).
- **library** = biblioteca (no "librería" → *bookstore*).
- **exit** = salida (no "éxito" → *success*).
- **embarrassed** = avergonzado (no "embarazada" → *pregnant*).

## Autoevaluación

> [!question]- ¿Cómo dices "renunciar a un trabajo"?
> To **quit** (one's job).

> [!question]- ¿Qué significa "actually"?
> En realidad / de hecho. "Actualmente" es *currently*.

> [!question]- ¿Cómo pides devolver algo en una tienda?
> I'd like to return this, please. (Can I get a refund?)

- Haz un role-play con una IA: llegada a un hotel con problema de reservación y luego una compra con devolución.
