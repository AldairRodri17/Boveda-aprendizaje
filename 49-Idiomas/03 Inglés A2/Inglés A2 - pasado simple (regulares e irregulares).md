# Inglés A2 - pasado simple (regulares e irregulares)

Parte de: [[49-Idiomas/03 Inglés A2/_Índice Inglés A2|Inglés A2]]

> [!info] Cómo avanzar
> `progreso`: **pendiente** → **viendo** → **visto** → **dominado**.

## Contenido

### Qué es
El **pasado simple** habla de acciones **terminadas en un momento específico del pasado**: ayer, la semana pasada, en 2020. Equivale a "trabajé", "fui", "hice".

### Cómo se forma
| | Todas las personas |
|---|---|
| Afirmativa | I **worked** / she **went** |
| Negativa | I **didn't work** / she **didn't go** |
| Pregunta | **Did** you **work**? / Where **did** she **go**? |
| Respuesta corta | Yes, I did. / No, she didn't. |

**Verbos regulares:** agregan **-ed**.
- work → work**ed**; live → live**d**; stop → stop**ped** (consonante final se duplica en sílaba acentuada corta); study → stud**ied**.
- Pronunciación: ver [[Terminaciones -ed y -s]].

**Verbos irregulares más usados (apréndelos de memoria):**
| Base | Pasado | | Base | Pasado |
|---|---|---|---|---|
| be | was / were | | make | made |
| have | had | | take | took |
| do | did | | give | gave |
| go | went | | find | found |
| get | got | | think | thought |
| say | said | | buy | bought |
| see | saw | | write | wrote |
| come | came | | break | broke |
| know | knew | | run | ran |
| tell | told | | leave | left |

**Clave:** con *did/didn't* el verbo va en forma **base**: ~~Did you went?~~ → Did you **go**?

**Expresiones de tiempo:** yesterday, last week/month/year, two days **ago**, in 2019, when I was a kid.

### Ejemplos
- We **deployed** the new version last night.
- I **didn't see** your message yesterday.
- **Did** the tests **pass**? — No, they didn't.
- She **broke** the build two hours **ago**.

### Errores comunes de hispanohablantes
- ~~I goed~~ → I **went**.
- ~~Did you saw…?~~ → Did you **see**…?
- ~~Before two days~~ → two days **ago**.
- Usar pasado simple sin tiempo definido cuando el inglés usa presente perfecto (ver [[Inglés B1 - presente perfecto]]).

## Autoevaluación

> [!question]- Pon en pasado: "I (buy) a new laptop and (think) it was expensive."
> I **bought** a new laptop and **thought** it was expensive.

> [!question]- Corrige: "Did you finished the report?"
> Did you **finish** the report?

> [!question]- Traduce: "Llegué hace tres días."
> I arrived three days **ago**.
