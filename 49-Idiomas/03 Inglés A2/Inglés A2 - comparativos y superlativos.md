# Inglés A2 - comparativos y superlativos

Parte de: [[49-Idiomas/03 Inglés A2/_Índice Inglés A2|Inglés A2]]

> [!info] Cómo avanzar
> `progreso`: **pendiente** → **viendo** → **visto** → **dominado**.

## Contenido

### Qué es
- **Comparativo:** compara dos cosas → "más rápido que".
- **Superlativo:** destaca una entre varias → "el más rápido".

### Cómo se forma
| Tipo de adjetivo | Comparativo | Superlativo |
|---|---|---|
| 1 sílaba | fast → fast**er** than | the fast**est** |
| 1 sílaba, consonante-vocal-consonante | big → big**ger** | the big**gest** |
| 2 sílabas terminadas en -y | easy → eas**ier** | the eas**iest** |
| 2 o más sílabas | expensive → **more** expensive | the **most** expensive |
| Irregulares | good → **better** | the **best** |
| | bad → **worse** | the **worst** |
| | far → **farther / further** | the **farthest / furthest** |
| | much/many → **more** | the **most** |
| | little → **less** | the **least** |

**Otras estructuras útiles:**
- Igualdad: **as fast as** (tan rápido como) / **not as expensive as**.
- Menos: **less** complicated **than**.
- Progresivo: It's getting **better and better**. / **more and more** popular.
- "Mientras más…": **The more** you practice, **the better** you speak.

### Ejemplos
- PostgreSQL is **cheaper than** SQL Server for small projects.
- Rust is **more difficult than** Python, but it's **faster**.
- This is **the worst** bug I've ever seen.
- My new laptop isn't **as heavy as** the old one.

### Errores comunes de hispanohablantes
- Doble comparativo: ~~more faster~~ → **faster**.
- ~~more good~~ → **better**; ~~the more bad~~ → **the worst**.
- *Than* vs. *that*: ~~bigger that~~ → bigger **than**.
- Olvidar *the* en superlativo: ~~It's best option.~~ → It's **the** best option.

## Autoevaluación

> [!question]- Completa: "Azure is (expensive) ___ than my VPS, but it's (reliable) ___ option I've used."
> **more expensive**; **the most reliable**.

> [!question]- Corrige: "This framework is more easier than the other."
> This framework is **easier than** the other.

> [!question]- Traduce: "Mientras más pruebas escribes, menos bugs tienes."
> The more tests you write, the fewer bugs you have.
