# Inglés A2 - can, could y should

Parte de: [[49-Idiomas/03 Inglés A2/_Índice Inglés A2|Inglés A2]]

> [!info] Cómo avanzar
> `progreso`: **pendiente** → **viendo** → **visto** → **dominado**.

## Contenido

### Qué es
**Can, could y should** son **verbos modales**: acompañan a otro verbo para expresar habilidad, permiso, posibilidad o consejo.

**Reglas de todos los modales:**
1. No llevan -s en tercera persona: ~~she cans~~ → she **can**.
2. Van seguidos del verbo **base sin "to"**: ~~can to swim~~ → **can swim**.
3. Forman negativa y pregunta solos (sin *do*): **can't**, **Can** you…?

### Cómo funciona
| Modal | Uso | Ejemplo |
|---|---|---|
| **can** | Habilidad presente | I **can** speak three languages. |
| | Permiso informal | **Can** I leave early today? |
| | Posibilidad | You **can** deploy from the portal. |
| **can't** | Imposibilidad / prohibición | You **can't** push to main. |
| **could** | Habilidad en pasado | I **could** swim when I was five. |
| | Petición educada | **Could** you review my PR, please? |
| | Posibilidad (menos segura) | It **could** be a cache problem. |
| **should** | Consejo / recomendación | You **should** add tests. |
| **shouldn't** | Consejo negativo | You **shouldn't** store passwords in plain text. |

### Grados de cortesía en peticiones
Can you…? (informal) → **Could you…?** (educado, el más usado en el trabajo) → Would you mind + -ing…? (muy educado).

### Ejemplos
- **Could** you send me the logs, please?
- We **should** update the dependencies before the release.
- I **can't** access the VPN. **Can** you check my permissions?
- It **could** take two or three days.

### Errores comunes de hispanohablantes
- ~~Can you to help me?~~ → Can you **help** me?
- ~~I can't to go.~~ → I can't **go**.
- Usar *can* en peticiones formales con clientes: mejor **could**.
- ~~You should to try.~~ → You should **try**.
